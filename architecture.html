Factory Inventory Management

Full-stack demo application with a Vue 3 single-page frontend, a Python FastAPI service, and JSON-backed mock data. No database — data is loaded into memory at startup and filtered on request.

Data
In-Memory JSON
server/data/*.json
  • Loaded once at startup
  • Filtered per request in Python
  • Mutations held in-process (lost on restart)
  • No DB, no cache, no ORM

Data Flow

1

User action

Filter change or page load in a Vue view triggers a call.

2

API client

client/src/api.js builds URLSearchParams, fires GET via axios.

3

FastAPI handler

Route in server/main.py filters the in-memory list by query params.

4

Pydantic validation

Response coerced to typed model, serialized to JSON.

5

Reactive render

Raw data stored in a ref; computed properties drive the UI.
